# Система мониторинга и анализа сетевого трафика
## Network Traffic Monitor v1.0

### Описание проекта
Дипломный проект, представляющий собой программное обеспечение для перехвата, анализа и визуализации сетевого трафика в реальном времени. Система предназначена для администрирования локальных сетей, выявления аномалий и потенциальных угроз безопасности, а также сбора и хранения статистики использования сетевых ресурсов.

Разработка выполнена в соответствии с требованиями ГОСТ 34.602-89 и предназначена для использования в учебных, исследовательских и административных целях.

### Функциональные возможности
- Перехват и парсинг сетевых пакетов протоколов TCP, UDP, ICMP
- Анализ трафика и выявление подозрительной активности:
  - сканирование портов
  - аномальное количество соединений
  - частые запросы
  - использование нестандартных и подозрительных портов
- Многопоточный графический интерфейс на базе PyQt6 без зависания основного потока
- Визуализация статистики и распределения протоколов с использованием matplotlib
- Сохранение логов трафика и событий безопасности в базу данных MS SQL Server
- Нагрузочное тестирование с генерацией TCP/UDP запросов
- Экспорт статистики в формат CSV
- Фильтрация, поиск и сортировка записей в журнале событий
- Гибкая настройка параметров анализа и подключения к базе данных через конфигурационный файл

### Технологический стек
- Язык программирования: Python 3.9+
- Графический интерфейс: PyQt6
- Захват и анализ трафика: Scapy, psutil
- Работа с базами данных: pyodbc
- Визуализация данных: Matplotlib, Pandas
- Логирование: встроенный модуль logging
- Система управления базами данных: MS SQL Server

### Системные требования
- Операционная система: Windows 10/11 (64-bit) или Linux (Ubuntu 20.04+)
- Процессор: Intel Core i3 или эквивалент
- Оперативная память: от 4 ГБ
- Свободное дисковое пространство: от 500 МБ
- Сетевой адаптер: Ethernet или Wi-Fi
- Программное обеспечение: Python 3.9+, MS SQL Server 2016+, ODBC Driver 17 for SQL Server
- Права доступа: запуск от имени администратора (обязательно для перехвата пакетов)

### Установка и настройка

1. Клонирование репозитория или распаковка архива проекта:
cd network_monitor

2. Создание и активация виртуального окружения:
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

3. Установка зависимостей:
pip install -r requirements.txt

4. Настройка базы данных:
- Убедитесь, что MS SQL Server запущен и доступен
- Отредактируйте параметры подключения в файле config.json
- При первом запуске приложение автоматически создаст базу данных TrafficMonitor и необходимые таблицы
- Для ручного создания структуры выполните скрипт schema.sql через SQL Server Management Studio

### Конфигурация
Основная настройка системы выполняется через файл config.json. Основные разделы:
- database: параметры подключения к MS SQL Server
- sniffer: настройки перехвата трафика
- analysis: пороги срабатывания детектора угроз и список подозрительных портов
- load_test: параметры генератора нагрузочного тестирования
- ui: интервал обновления интерфейса и лимиты отображения

### Запуск приложения
Для корректного перехвата сетевых пакетов необходимо запустить терминал или командную строку от имени администратора.

Запуск выполняется командой:
python main.py

После запуска откроется главное окно приложения. Для начала мониторинга нажмите кнопку "Запуск анализа".
